# বাংলাদেশ জিও রেজিস্ট্রি (Bangladesh Geo Registry)

`nuhil/bangladesh-geocode` ডেটাসেট দিয়ে বানানো একটা Vue 3 + Vite ফ্রন্টএন্ড, UI-এর বেস হিসেবে
**Bootstrap 5** ব্যবহার করা হয়েছে। বিভাগ → জেলা → উপজেলা → ইউনিয়ন — চার লেভেলের পুরো হায়ারার্কি
ব্রাউজ করা যায়, সার্চ করা যায়, আর প্রতিটা জেলার লোকেশন ম্যাপে (Leaflet) দেখা যায়। প্রতিটা
ইন্টারঅ্যাকশনে (তালিকা খোলা/বন্ধ, সার্চ রেজাল্ট, ডিটেইল কার্ড বদলানো) Vue-এর `<Transition>` দিয়ে
স্মুথ অ্যানিমেশন যোগ করা আছে — কোনো hard-cut নেই। UI-এর বেস স্টাইলিং **Bootstrap 5** দিয়ে করা (navbar, list-group,
card, badge ইত্যাদি ক্লাস), আর পুরো ইন্টারঅ্যাকশন (এক্সপ্যান্ড/কোলাপ্স, সিলেকশন, সার্চ, ম্যাপ সিংক)
সম্পূর্ণ Vue-এর reactive state দিয়ে কন্ট্রোল করা — মানে Bootstrap-এর নিজস্ব JS/data-bs-* লাগেনি,
সব কিছু ডাইনামিক ও ভিউ-চালিত।

## চালানোর নিয়ম (কম্পিউটারে)

তোমার কম্পিউটারে [Node.js](https://nodejs.org) (v18+) ইনস্টল থাকতে হবে।

```bash
# 1) এই ফোল্ডারে ঢোকো
cd bd-geo-explorer

# 2) ডিপেন্ডেন্সি ইনস্টল করো (vue + bootstrap + leaflet + vite)
npm install

# 3) ডেভ সার্ভার চালু করো
npm run dev
```

টার্মিনালে একটা লোকাল লিংক দেখাবে (সাধারণত `http://localhost:5173`) — ব্রাউজারে খুললেই অ্যাপ চলবে।

## প্রোডাকশন বিল্ড / ডিপ্লয়

```bash
npm run build
```

এটা `dist/` ফোল্ডারে স্ট্যাটিক ফাইল বানাবে — এই ফোল্ডারটা Vercel, Netlify, GitHub Pages বা যেকোনো
স্ট্যাটিক হোস্টিং-এ আপলোড করলেই সাইট লাইভ হয়ে যাবে। Vercel দিয়ে করতে চাইলে:

```bash
npm i -g vercel
vercel
```

## যা যা আছে

- **হায়ারার্কি ব্রাউজার** — বাম পাশে বিভাগ থেকে শুরু করে ইউনিয়ন পর্যন্ত এক্সপ্যান্ড করা যায়।
- **সার্চ** — উপরে সার্চ বক্সে ইংরেজি বা বাংলা নাম লিখলে সব লেভেল থেকে ফলাফল আসবে।
- **ম্যাপ** — প্রতিটা জেলার সরকারি অক্ষাংশ/দ্রাঘিমাংশ ডেটা দিয়ে মার্কার বসানো, বিভাগ অনুযায়ী রঙ
  আলাদা। মার্কারে ক্লিক করলে সেই জেলা বাম পাশের তালিকায় ও নিচের ডিটেইল কার্ডে সিলেক্ট হয়ে যাবে।
- **ডিটেইল কার্ড** — নির্বাচিত বিভাগ/জেলা/উপজেলা/ইউনিয়নের নাম (বাংলা+ইংরেজি), ব্রেডক্রাম্ব ও
  সরকারি ওয়েবসাইট লিংক দেখায়।
- **অ্যানিমেশন** — ব্র্যান্ড লোগোর এন্ট্রান্স অ্যানিমেশন, তালিকা এক্সপ্যান্ড/কোলাপ্স হওয়ার সময়
  স্মুথ height ট্রানজিশন (CSS grid ট্রিক, কোনো JS height ক্যালকুলেশন ছাড়াই), সার্চ ড্রপডাউন ও
  ডিটেইল কার্ড fade+slide ট্রানজিশন, রো-হোভারে হালকা শিফট — সবকিছু `prefers-reduced-motion`
  রেসপেক্ট করে।

## কাস্টমাইজেশন — কোথায় কী বদলাবে

- **রঙ/ফন্ট বদলাতে** → `src/style.css`-এ `:root` ভ্যারিয়েবলগুলো বদলাও (`--forest`, `--red`,
  `--gold`, `--paper`, `--serif`, `--sans`)।
- **ম্যাপের বেস টাইল বদলাতে** → `src/components/GeoMap.vue`-এ `L.tileLayer(...)`-এর URL বদলাও।
  এখন CARTO-র লাইট টাইল ব্যবহার হচ্ছে; চাইলে `openstreetmap.org` বা Mapbox/অন্য প্রোভাইডারের
  টাইল ইউআরএল বসাতে পারবে।
- **নতুন ডেটা কলাম যোগ করতে** (যেমন postal code, population) → `src/data/*.json` ফাইলে ফিল্ড
  যোগ করো, তারপর `App.vue`-এর `detail` computed অংশে সেটা দেখাও।
- **ইউনিয়নের লোকেশন যোগ করতে** — এখন শুধু জেলার lat/lon আছে বলে ইউনিয়ন লেভেলে আলাদা পিন নেই।
  ইউনিয়ন ডেটাতে `lat`/`lon` যোগ করলে `GeoMap.vue`-এ আরেকটা মার্কার লেয়ার বানিয়ে দেখানো যাবে।
